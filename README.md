# Programmer's Memory Game

A memory matching game where players find pairs of programming language and developer tool logos.

## Live Deployment
[Live App on Netlify](https://programmersmemory.netlify.app)

## Tech Stack
* React
* Vite

## Installation & Local Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/BHAT-AAQIB11/Programmer-s-Memory.git
   cd programmers-memory
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run local server:**
   ```bash
   npm run dev
   ```

## Project Directory
* `src/` - React components, card icons and application code
* `index.html` - HTML entry point
* `vite.config.js` - Build configuration
